# Aryan Rusia — Portfolio

Personal site rebuilt from the original [Portfolio-Aryan](https://github.com/Aryan-Rusia-2/Portfolio-Aryan) content: projects, experience, research write-ups, and assets.

## Stack

Vite, React, TypeScript, Tailwind CSS v4, Framer Motion.

## Scripts

```bash
npm install
npm run dev
npm run build
```

Open `http://localhost:5173`.
